# 《僵尸围城》Boss 细招式表 × 每两波一 Boss

整理时间：台北时间 2026-11-03 11:51  
依据：`boss-plan.md`、`game_data.gd` / `boss_brain.gd` / `hazards.gd`、武器数值  
约束：**只设计不写代码**。预警时长未注明时沿用现网：`charge/charge2` 0.8s 红通道 → 冲 1.0s；`slam` 0.9s 红圈；`rocks` 0.55s 落点；`storm` 0.7s；`fog/fogring` 0.6/0.7s 绿圈；`fan` 0.6s；`wave` 0.9s 后冲击波；`call/elites` 0.8/1.0s 紫圈；`shield` 0.7s；`scream` 0.9s。阶段切换锁血 ~1.8s。闪光可打断蓄力（Boss 晕极短）。冰永不冻 Boss（只减速×0.7）。

伤害写法：`×伤害` = Boss 表 `damage` × 波次 `damage_scale`。招式间隔 = 阶段 `gap`。

## A. 波次总表（1–15）

**规则**：偶数波 = Boss；奇数波 = 普通/过渡；**第 15 波额外终局**（偶数节奏 + 尸王压轴）。  
**特殊共存**：酸雨留在 **8**、断电留在 **12**、尸王留在 **15**——与 Boss **同波叠加**，但降强度（见下）。

| 波 | 类型 | 内容 | 杂兵策略 |
| --- | --- | --- | --- |
| 1 | 普通 | 先头 walker | 正常 |
| **2** | **Mini-Boss** | **裂颚先锋** | 杂兵 ≤ 现 W2 的 50%；Boss 在场出怪间隔 ×1.35 |
| 3 | 普通 | 毒液教学 spitter | 正常略减（给商店回血） |
| **4** | **Boss** | **屠夫**（从原 5 前移） | 杂兵 ≈ 原 W5 的 70%；出怪慢 |
| 5 | 普通 | 自爆 + 分裂预习 | 正常 |
| **6** | **Boss** | **覆甲巨像** | 少护盾兵（别叠破盾题）；坦克 ≤1；出怪慢 |
| 7 | 普通 | 铁壁/护盾预习 + 商店攒冰火钱 | 正常 |
| **8** | **Boss + 酸雨** | **瘟疫母体** | 酸雨 **间隔 ×1.5、单波滴数 −1**（Boss 存活时）；Boss 少放 `fog`（改 fan/call），避免绿圈分不清；杂兵偏喷吐/分裂 |
| 9 | 普通 | 火药桶/召唤者 | 正常 |
| **10** | **Boss** | **再生坟主** | 禁叠满毒雾杂波；出怪慢；鼓励已解锁冰/火 |
| 11 | 普通 | 黑夜向气球/尖叫 | 正常（可随机夜战） |
| **12** | **Boss + 断电** | **掘地领主** | 断电保留；Boss 预警改 **高对比黄圈/土堆**；潜伏者可作杂兵但数量 −40%；出怪慢 |
| 13 | 普通 | 尸潮（略减于现 W13） | 给 14 前修墙买弹 |
| **14** | **Boss** | **镜面女皇** | 少护盾兵；出怪慢；预告「别正面点射」 |
| **15** | **终局 Boss** | **尸王** | 维持现规：禁天气、可空投；杂兵中等；倒地清场胜利 |

**事件**：Boss 波仍 **禁随机天气**（8/12 的酸雨、断电是 **剧本特殊**，不是随机事件）；可空投。7↔9、11↔13 可出随机天气/先遣。

**节奏一句话**：打一波怪 → 打一场 Boss → 商店；全程 7 场偶数 Boss + 1 场终局 = **8 场 Boss 战**。

## B. 细招式表

### 共用可读约定
- **可打断**：闪光（取消蓄力）；另注冰减速/霰弹击退/诱饵改道等。  
- **冷却**：用阶段 `gap`；同招不连续（现逻辑 `_last`）。  
- **Mini**：1–2 阶段、血薄、招式池 ≤3。

## C. 实现分期（不改架构优先）

### 第 1 期｜配表 + 现有 move（可先上节奏）
1. **波次表改偶数 Boss**：W2 先锋、W4 屠夫前移、W15 尸王不动。  
2. **裂颚先锋**：只复用 charge/slam/rocks，新 kind + 矮 HP。  
3. **屠夫改造**：P2 打断条件（可先只认闪光）。  
4. **瘟疫 W8 + 酸雨稀化**：事件与 `fog` 权重调整。  
5. **尸王 P1 +shield**：一行配表。

→ 先做到「每两波一 Boss」可玩，克制题尚浅。

### 第 2 期｜扩展 `absorb` / 状态（无新 hazard 类型）
6. **覆甲巨像**（阈值 `absorb`）→ W6  
7. **再生坟主**（tick 再生 + 吃 chill/burn）→ W10  

### 第 3 期｜要新预警/移动态
8. **掘地领主**：`burrow` 态 + 土堆绘制 + 逼出判定 → W12+断电  
9. **镜面女皇**：子弹/光束反射钩子 + `reflect_aura` → W14  

### 刻意后置
冲锋督军多 lane 连预告、电磁短 EMP、粘胶地面 —— 作替换皮或第 4 期。
