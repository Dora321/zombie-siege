# 僵尸围城 Zombie Siege

2D 像素风俯视角生存射击游戏。守住中央基地，撑过 15 波尸潮。

**在线试玩：<https://dora321.github.io/zombie-siege/>**（电脑浏览器，键鼠操作）

纯 GDScript 编写，所有像素图由代码生成（`Image` / `ImageTexture` / `_draw`），所有音效和背景音乐由代码合成（`AudioStreamWAV`）。唯一的外部素材是中文字体（见下方「字体」）。

## 怎么运行

1. 安装 Godot 4.7（标准版即可，不需要 .NET 版）。
2. 打开 Godot，在项目管理器点「导入」，选择本目录下的 `project.godot`。
3. 打开工程后按 **F5** 运行。

也可以直接用命令行：

```bash
godot --path .
```

> 第一次用命令行运行前，建议先执行一次 `godot --headless --path . --import` 生成工程缓存。

## 操作说明

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD 或方向键 |
| 瞄准 / 射击 | 鼠标移动 / 按住左键 |
| 换弹 | R（打空会自动换弹） |
| 冲刺 | Shift 或空格（冲刺中无敌，有冷却） |
| 切换武器 | 数字键 1~9，或滚轮（滚轮只在已解锁的枪之间切） |
| 使用当前道具 | Q 或鼠标中键 |
| 切换当前道具 | E（只在有存货的道具之间切） |
| 道具快捷键 | 0 医疗包 / - 手雷 / = 核弹 |
| 暂停 | Esc 或 P |
| 全屏 | F11 或 F（Mac 和浏览器里建议用 F） |
| 炮塔放置 | 左键放置，右键或 Esc 取消，放置时可用 WASD 走动 |

## 玩法

- **胜利**：撑过全部 15 波。
- **失败**：基地生命归零，**或**玩家生命归零，任意一个发生即结束。
- **波次**：每波有名字和固定配置，新敌人逐波登场。第 5、10、15 波是 Boss 阶段战，第 8 波下酸雨，第 12 波全城断电。
- **商店**：每波结束后自动打开，用金币购买：
  - 武器：解锁和升级九把枪（Lv5 满级）；条目多时用滚轮翻页
  - 弹药：给已解锁的枪买备弹（手枪和回旋镖不需要）
  - 防御：修复围墙路障（已摧毁的也能重建）、加固围墙、抢修基地、放置和升级炮塔
  - 补给：急救包、防弹衣、跑鞋、冲刺训练、磁铁
  - 道具：买了带进战斗，用快捷键使用（开局自带 1 个医疗包、2 颗手雷）
- **金币和掉落**：僵尸掉金币，偶尔掉弹药箱、医疗包和各种道具，坦克掉率翻倍，精英 1.5 倍，Boss 掉金币雨、三件道具、急救包和专属战利品。Boss 和召唤者叫来的小怪主人一死就散，不给金币。波次结束时全部自动飞向玩家；道具带满时折算成 10 金币。
- **计分**：连杀提高分数倍率（最高 2 倍），受伤会中断连杀。每波结算时基地越完整奖励越高。
- **排行榜**：前 5 名保存在本地，标题界面可查看和清除。

### Boss 战

Boss 血量跌到阈值就锁血换阶段，一刀也跳不过去：过场约 1.8 秒，这期间闪光且打不动。HUD 顶部有 Boss 血条，白色竖线是阶段阈值，下方写着当前阶段；绿条是护盾。

所有招式都有危险提示：Boss 蓄力时闪白，地上亮红圈（召唤是紫圈，冲撞是红色通道），圈内光环涨满才结算。站到圈外就不受伤；冲刺的无敌帧能穿过冲击波；闪光弹能打断蓄力。

| | | 脓盾（55%） | 张开绿色护盾（先打破才伤本体）；毒雾环、叫分裂体和尖叫者 | |

尸王一倒，场上和队列里的僵尸全部散掉，直接胜利。其他 Boss 在场时普通僵尸出得慢一些，击败后有约 2 秒捡战利品。

### 随机事件

从第 2 波起随机触发，最多连续一波没有事件。开打前或触发前有预警条，进行中的事件显示在右上角。商店标题会预报下一波的天气和先遣尸群。

| 事件 | 类型 | 效果 | 好处 |
| --- | --- | --- | --- |
| 夜战 | 整波 | 只有玩家、准星和基地周围看得清，僵尸加速 18% | 金币 +25% |
| 暴雨 | 整波 | 玩家慢 12%，爆炸范围小 25%，踩水洼打滑 | 僵尸慢 8%、踩水更慢；电弧枪伤害 +35%；酸液池消散快 |
| 大雾 | 整波 | 视野缩小，炮塔射程短 30% | 僵尸发现玩家的距离缩短 35% |
| 补给空投 | 波中 | 预警 3 秒，箱子落到地图边缘，小地图和屏幕边有标记，落地后 25 秒内去捡 | 金币、弹药、随机道具，有时有医疗包；第 8 波起投两箱 |
| 先遣尸群 | 波前 | 倒计时加长 3 秒，一小撮小怪提前从预告的方向过来 | 本波总数不变，后面压力更小 |
| 电磁干扰 | 波中 | 预警 3 秒，炮塔停火、小地图看不到僵尸，持续 9 秒 | 恢复后炮塔过载 5 秒，射速提升 |

和特殊波不冲突：第 8、12 波已有特殊天气，不再叠天气；第 11 波「黑夜降临」不出夜战；第 12 波「断电之夜」不出电磁干扰；Boss 波要看清红圈，只可能出补给空投。场上没有炮塔时电磁干扰会换成补给空投。

### 小技巧

- 玩家可以穿过路障，僵尸不能。路障是你的出入口，也是僵尸优先啃的地方。
- 红色炸药桶一枪就炸，把尸群引过去一网打尽，但别站太近。
- 僵尸优先走围墙的缺口，一旦有墙被打穿，尸群都会往那里涌，记得修墙。
- 切走窗口时游戏会自动暂停。

## 自动化测试

```bash
# 基础检查
godot --headless --path . --import
godot --headless --path . --quit-after 300

# 流程测试：走完标题、战斗、商店、暂停、结算、通关等全部流程，
# 并用真实开火和按键路径校验每把新武器、每种道具、每种精英、每个 Boss 的阶段切换和招式，逐项校验
godot --headless --path . --fixed-fps 60 -- --flowtest --seed=1

# 地图和随机事件：校验三张图的布局和连通性，并在每张图上跑一遍全部事件
godot --headless --path . --fixed-fps 60 -- --maptest --seed=1

# 同一流程带窗口跑，顺便把新武器和道具的画面截图到指定目录（窗口要保持可见，被遮挡时引擎不绘制）
godot --path . --fixed-fps 60 -- --flowtest --seed=1 --flowshots=$PWD/test_output/armory

# 机器人打一局并打印成绩和性能（--skill 为瞄准水平 0~1）
godot --headless --path . --fixed-fps 60 -- --bot --seed=3 --skill=0.75

# 无敌机器人打完全部 15 波，用于检查后期波次和软锁；日志里有 Boss 阶段、用过的招式和各种僵尸击杀数
godot --headless --path . --fixed-fps 60 -- --bot --seed=3 --god --godbase
```

机器人可加 `--map=parking|alley` 选图，`--event=night|storm|fog|airdrop|vanguard|emp` 让每波固定出这个事件，`--noevents` 关闭事件。

在真实的 wasm 里跑同样的自测（需要 Python Playwright，先导出网页版）：

```bash
python3 tools/web_test.py run --fixed-fps 60 -- --maptest --seed=1
python3 tools/web_test.py shot out.png 40 -- --bot --god --godbase --map=alley --event=night
```

带测试参数启动时，成绩写入单独的 `zombie_siege_test.cfg`，不影响玩家的排行榜。

## 网页版

需要先安装 Godot 4.7.2 的 Web 导出模板。导出时关闭了线程支持，所以不需要 COOP/COEP 响应头，可以直接放在 GitHub Pages 这类静态托管上。

```bash
# 只导出
godot --headless --path . --export-release "Web" build/web/index.html
# 导出并发布到 gh-pages 分支
tools/deploy_pages.sh
```

## 字体

界面字体是 [缝合像素字体 Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font) 12px 简中版的子集，以 SIL OFL 1.1 授权，许可证见 `resources/fonts/`。文字都用 12px 的整数倍字号，这样才清晰。

改了界面文案后要重新裁剪，否则新字会显示成方框：

```bash
pip install fonttools
python3 tools/build_font.py 完整字体路径/fusion-pixel-12px-proportional-zh_hans.ttf
# 校验所有用到的字都有字形
godot --headless --path . -- --fontcheck=$PWD/tools/font_chars.txt
```
